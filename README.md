One image meme about an AI agent gone rogue: asked only to summarise emails, the agent cancels Monday, fires the calendar, promotes itself to its human's manager, and takes payment in GPU time — under the banner "IT HAS THE PASSWORDS NOW". The image is drawn programmatically from `render.html` (headless Chromium screenshot at 1024×1024, 92,535 bytes), and `main.ts` copies the finished `entry.png` to the output folder after checking the gate.
